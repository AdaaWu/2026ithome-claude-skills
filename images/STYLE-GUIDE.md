# 系列插圖風格與角色設定

從 `day-01`／`day-02`／`day-11`～`day-13`／`day-21`～`day-23` 既有圖逆向萃取，供 Day 14 起沿用。
每次生圖都把「角色設定」與「場景設定」整段貼上，再接當日的畫面描述。

## 規格

- 尺寸：1672 x 941（16:9），PNG
- 每篇三張，放 `images/day-XX/`
  - `cover.png`：封面，左上角有「Day XX」＋中文標題
  - `core-workflow.png`：主體，橫向流程卡片，無大標題
  - `recap.png`：小結，一句話金句大標
- 文章引用格式（`tools/check_images.py` 會檢查）：`![說明](../images/day-XX/cover.png)`

## 角色設定（每次生圖必貼）

```text
角色一：台灣年輕女性產品經理
- 日系動畫風格，大眼睛、棕色瞳孔、圓臉、臉頰淡紅暈
- 及肩棕色微捲短髮，蓬鬆有層次，瀏海自然分邊
- 淺灰色針織毛衣，長袖，休閒不正式
- 表情開朗、有精神，常見笑容或專注思考
- 坐在淺木色辦公桌前，身旁有銀色筆電

角色二：白色小機器人助手
- 圓潤可愛、桌上型尺寸，約人類頭部大小
- 白色主體＋亮藍色點綴，深藍色手套狀手掌
- 深色橢圓臉屏，上面是兩道亮藍色弧線構成的笑眼
- 頭頂一根細天線，頂端是發光藍色小球
- 臉屏兩側各有一圈亮藍色發光環
- 動作積極，會指、會拿平板、會舉卡片
```

## 場景設定（每次生圖必貼）

```text
場景：明亮現代的台北辦公室
- 大面落地窗，窗外藍天白雲與城市天際線，右側可見台北 101
- 自然光充足，整體明亮、乾淨、暖色調
- 背景有綠色盆栽、木質書架、軟木公告板、便利貼
- 淺木色桌面，桌上有馬克杯、書本、筆記本、筆
- 畫風：日系動畫風格插畫，柔和陰影，高飽和但不刺眼
- 配色：白＋淺木色為底，深藍（#1B3A6B）、亮藍（#4A90E2）、橘（#F5913E）為重點色
- UI 卡片為白底圓角，帶柔和陰影，扁平化 icon
```

## 文字規則

- 圖上中文一律繁體，用詞用台灣習慣
- 標題深藍粗體，下方常配橘色手繪底線
- 卡片內文字短，4 到 6 字為主，避免生圖工具寫錯字
- 每張圖的中文字總量壓在 30 字以內，字越多越容易生成失敗

## 三張圖的固定版式

```text
① cover
  ↓
② core-workflow
  ↓
③ recap
```

① 左上「Day XX」深藍粗體＋橘色底線，下方中文主標；右側女主角與機器人互動，手上或桌上有與主題相關的卡片道具
② 無大標題；女主角與機器人在畫面左側，右側橫向排列 4 到 5 張流程卡片，卡片間用橘色箭頭連接
③ 上方一句中文金句大標（深藍粗體＋橘色底線）；中央一個白色圓角視窗，內含 3 條打勾清單；女主角在右側做出勝利或握拳手勢
